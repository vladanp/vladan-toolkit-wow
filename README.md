# Vladan Toolkit

A personal all-in-one addon for **World of Warcraft: Forever**. Every feature is a small module you can switch on or off.

Type **`/vt`** in-game (or use the addon compartment on the minimap) to open the settings.

## Features
| Feature | What it does |
|---|---|
| Faster auto-loot | Grabs all loot instantly when auto-loot is on. |
| Sell junk | Sells all grey items when you open a vendor. |
| Auto repair | Repairs all gear at vendors that can repair. |
| Auto-buy reagents | Tops up a per-character list at vendors: `/vt buy <shift-click item> <count>` (0 removes, `/vt buy` lists). |
| XP tracker | XP bar (with rested), XP per hour, projected level-up time and clock time, kills and quests to level. Hover for details, drag to move, right-click to reset. |
| Auto open all mail | Presses the mailbox's Open All button for you (skips COD and GM mail). |
| Missing-buff reminder | Out of combat, pulsing icons for your missing class buffs. Hover for the spell, drag to move. |
| Copyable chat links | Web links in chat become clickable; click, then Ctrl+C. |

## Install
**WowUp** (auto-updates): Get Addons → Install from URL → `https://github.com/vladanp/vladan-toolkit-wow`.
Every change pushed to `main` publishes a new release automatically.

Manual: download the `-forever.zip` from [Releases](https://github.com/vladanp/vladan-toolkit-wow/releases) and extract it into `World of Warcraft\<Forever folder>\Interface\AddOns`.

See [CLAUDE.md](CLAUDE.md) for how to add a feature.
